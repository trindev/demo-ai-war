## Direction contract

THESIS: A pickup is a book of coupons, request, verify, weigh, deliver, each one stamped when it is done and never removed. The surface refuses the floating rounded-card dashboard with soft shadows and pill badges.

OWN-WORLD: White coupon stock on a cool grey-green table. Ruled frames in navy-black ink, hairline inner rules, tabbed coupon heads, dashed perforations between stubs. Carrier green for the shell and primary action, carbon purple for every filled-in figure, void red and ink-green only as stamps. Athiti for heads and figures, Anuphan for reading text. Admin is the same book at night: dark stock, light rules, lavender figures.

STORY: The member sees where their pickup is in the book; the driver works one coupon at a time; the admin reads ruled ledgers; every number is traceable to a weighed coupon.

FIRST VIEWPORT: Member, phone. Green cover band with the member's name and points box. Below it the request steps as numbered coupons with tab heads. Each existing request is a coupon: tab head with number and slot, four stage stubs across with one stamp on the current stage and a void strike on earlier ones, a ruled figure grid, bag codes, and the QR behind a perforation as a disclosure that opens at full width (a QR has to be scanned from arm's length at a doorway, so it is shown large on demand, not as a thumbnail stub). Primary action is the full-width green button at the end of step 3.

FORM: jet-age ticket wallet (catalog challenger, chosen by the owner over the assigned direction); seed:e9917dfc8734fe95. Signature move: stage stubs that stamp. Motion: a stamp lands once when a stage completes. Driver: the sheet under the route map is the map's selection detail (tapping a pin changes it), not a second copy of the stop list.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
